Lokale Vorschau ohne Upload

Browserlokale Format-Demo

Diese statische Demo prüft nur lokal im Browser, ob eine Datei grob zum erwarteten Vier-Spalten-Format passt. Es werden keine Rohdaten hochgeladen, gespeichert oder an APIs gesendet.

Eingabe

Unterstützt lokale 23andMe-artige TSV/CSV-Dateien mit rsid, chromosome, position, genotype.

Grenzen

  • Keine VCF-Erzeugung im Browser.
  • Keine Genotyp-Uploads und keine Server-Komponente.
  • Keine dbSNP-, FASTA- oder Build-Erkennung innerhalb der Demo.
  • Nur Vorschau, Formatcheck und Risiko-Hinweise.

Für echte Konvertierung bitte weiter die Desktop-App oder die CLI Make23toVCF3.py --input ... verwenden.
